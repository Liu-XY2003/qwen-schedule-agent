## 硬瓶颈（决定二阶段能不能成）

**抽取准确率 52%**。具体失败模式：

| 类型 | 例子 | 严重度 |
|---|---|---|
| 多件事抽不全 | "三件事"只抽到一两件 | 🔴 高 |
| 时长绑定错 | "前两个各一小时"全填默认 | 🔴 高 |
| 约束漏抽 | "周三上午别排"没生成 keep_free | 🟠 中 |
| 语义错位 | "陪家人"（是约束）被当成任务 | 🟠 中 |
| 应澄清却拒答 | "帮我安排点事" → reject 而非 clarify | 🟡 低 |

**共同点：瓶颈是"多实体 + 属性绑定"，不是理解中文。** 这类问题训练数据能系统性解决。
