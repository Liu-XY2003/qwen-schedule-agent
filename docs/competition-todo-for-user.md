# 赛事办理清单（线下自行完成）

> 开发侧我来推进。这份清单是**只有你能做**的事，按紧急度排序。
> 涉及具体日期的地方以本校通知和组委会官方通知为准。

---

## 🔴 本周必做（约 6 周倒计时）

### 1. 查本校校赛通知
- **去哪**：教务处 / 软件学院 / 校团委 官网，搜「软件创新大赛」「第二十届」
- **找什么**：报名截止日、提交材料清单、提交方式（系统/邮箱）
- **参考节奏**：往届 12 月上旬截止报名、12 月中下旬校赛答辩

### 2. 发一封邮件给组委会（很重要，决定后面怎么走）
问两个问题，**保留邮件回复作为证据**：

> 1. 同一作品同期参加「挑战杯」校赛是否违反"未参加过其他公开比赛"的规定？
> 2. 匿名评审是否覆盖开源仓库链接（GitHub）？还是只需提交源码包？

**为什么必须先问**：你的项目在 GitHub 上是公开的，账号可关联到人。如果仓库算"材料"，
就需要做匿名处理（源码包 / 匿名镜像账号），这个决定影响后面所有材料怎么准备。

### 3. 组队与指导老师
- 规则：团队 ≤6 人（队长 1 + 队员 ≤3 + 指导老师 ≤2），可跨校跨专业
- **找指导老师**：需要老师签字/盖章的表格通常要提前打招呼
- 个人项目建议补 1–2 人：一个管文档/答辩，一个管视频/UI

## 🟠 11 月中下旬

### 4. 申请软件著作权（如果还没办）
- 个人可申请，官方登记**免费**，周期约 30–60 工作日（加急需付费）
- 现在办，12 月提交时可能还拿不到证 —— 先确认校赛是否**必须**提交证书还是可以先声明
- 材料：源代码前后各 30 页、软件说明书

### 5. 准备源码提交包（等第 2 步的回复再定方案）
- 若需匿名：用 `git archive` 导出 zip，**不含 .git 目录**
- 检查导出的包里没有 `local/schedule.db`、`backup/`、`_archive/`
- 我可以给你写个导出脚本

### 6. 匿名版材料自查
- [ ] 文档里没有校名、姓名、指导老师、学院、专业、班级
- [ ] PPT 页脚/母版没有学校 logo
- [ ] 演示视频里没有个人信息、真实 IP
- [ ] 截图已脱敏（**已完成**，`docs/screenshots/` 7 张都是中性数据）
- [ ] 如果有人名水印、个人主页链接，去掉

## ⚠️ 三个容易踩的坑

1. **不要等开发做完再准备材料。** 技术报告和视频可以基于现有成果先写，
   `docs/competition-materials.md` 里列的所有创新点和数据现在都已经有了。
2. **不要在材料里贴 GitHub 链接而不先确认匿名口径。** 一旦被判违规，成果再好也没用。
3. **别忽略"开源比例说明"。** 用了 Qwen3 / llama.cpp / FastAPI / Compose 要写清楚，
   藏着反而扣分；自己写的部分（契约设计、约束解码、求解器、数据集生成）要突出。
