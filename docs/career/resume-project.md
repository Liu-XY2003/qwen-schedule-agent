## 本地优先的 AI 日程助手｜2026.09-至今｜独立开发（全栈）

**摘要**：一句话加日程、或贴一段杂乱待办，本机小模型（Qwen3 0.6B–4B）即可抽取成结构化工具调用并排出可行周计划，数据不出本机；核显端到端 **641ms**，结构合规 **4372/4372**。

**技术问题**：小模型自由生成的 JSON 不可靠，无法安全驱动工具；让它推算"下周三"这类日期会系统性出错，且**错误是静默的**；同一份结构要被解码、训练、校验、工具四处消费，手写必然漂移。

**解决方案**：①**约束解码**——Schema 编译成 GBNF 逐 token 约束，格式不可能非法；再让契约只允许相对时间、绝对日期由代码解析，从根上消掉"模型算错日期"。②**单一事实源**——一份 Schema 派生解码语法、LoRA 标签、校验与 **MCP 工具签名**，CI 断言零漂移，客户端零适配。③**反向构造 + LoRA**——先定真值再渲染中文，标签由构造保证正确，4000 条完成微调。④**规划交给求解器**——CP-SAT 排周计划（21–32ms），排不出时定位冲突；规则层接管结构化字段，全对率 **4%→39%**。

**成果**：核显 641ms；约束合规 4372/4372；100+ 测试全绿；开源 MIT，Web + Android + MCP 服务端。技术栈 llama.cpp/GGUF、GBNF、LoRA、CP-SAT、FastAPI、Compose。

**展望**：二阶段补局部重排与多轮协商，三阶段接语音。日程是天然的意图入口——以本项目为**入口 Agent**，把"这周怎么安排"解析成结构化约束，即成为调用其他 Agent 与工具集的依据，让 AI 自动完成日常工作。
