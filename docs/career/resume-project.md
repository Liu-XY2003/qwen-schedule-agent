**2026.09 - 至今｜基于 LoRA 微调后 Qwen3 的 AI 日程助手｜独立开发（全栈）**

**项目摘要**：一句话加日程，0.6B 抽取成结构化调用；贴一段待办，4B 规划出本周计划。

**技术问题**：小模型生成的 JSON 不可靠；让它推算日期会系统性出错且**静默**；同一结构被解码、训练、校验、工具四处消费，手写必然漂移。

**解决方案**：①**约束解码**——Schema 编译成 GBNF 逐 token 约束，格式不可能非法；契约只许相对日期，绝对时间由代码算。②**单一事实源（MCP 思想）**——一份 Schema 派生解码语法、LoRA 标签、校验与 MCP 工具签名，CI 断言零漂移。③**反向构造 + LoRA**——先采样真值再渲染中文，标签由构造保证正确，4000 条微调。④**规划交给求解器**——CP-SAT 排周计划（21–32ms），排不出时定位冲突；规则层补抽字段，全对率 **4%→39%**。

**最终成果**：核显 641ms；约束合规 4372/4372；100+ 测试全通过；开源 MIT，Web + Android + MCP 服务端。

**技术栈**：llama.cpp/GGUF、GBNF、LoRA、CP-SAT、FastAPI、Compose。

**项目展望**：下阶段补局部重排与多轮协商。日程是天然的意图入口——把"这周怎么安排"解析成约束，即可调度其他 Agent 与工具集。
