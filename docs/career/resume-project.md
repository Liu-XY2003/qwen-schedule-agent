## 本地优先的 AI 日程助手｜2026.09-至今｜独立开发（全栈）

**摘要**：一句话加日程或贴一段杂乱待办，本机小模型（Qwen3 0.6B–4B）即抽取成结构化工具调用并排出可行周计划，数据不出本机；核显端到端 **641ms**，结构合规 **4372/4372**。

**技术问题**：小模型自由生成 JSON 不可靠，难以驱动工具；让模型算"下周三"这类日期会系统性出错且**静默**；同一结构被解码语法、训练标签、校验、工具暴露四处消费，手写必然漂移。

**解决方案**：①**约束解码**——Schema 编译成 GBNF 逐 token 约束，格式不可能非法；契约只允许相对日期，绝对时间由确定性代码解析。②**一份 Schema 四处消费（MCP 思想）**——单一事实源派生解码语法、LoRA 标签、校验与 **MCP 工具 `inputSchema`**，CI 断言零漂移，客户端零适配。③**反向构造 + LoRA**——先采样结构化真值再渲染中文，标签由构造保证正确，4000 条完成微调。④**规划交给求解器**——CP-SAT 排周计划（21–32ms），不可行时软化约束定位冲突；规则层接管结构化字段，全对率 **4%→39%**。

**成果**：核显 641ms；约束合规 4372/4372；100+ 测试全绿；开源 MIT，Web + Android + MCP 服务端。技术栈 llama.cpp/GGUF、GBNF、LoRA、CP-SAT、FastAPI、Compose。

**展望**：二阶段补局部重排与多轮协商，三阶段接语音。日程是天然的意图入口——以本项目为**入口 Agent**，把"这周怎么安排"解析成结构化约束，即成为调用其他 Agent 与工具集的依据，让 AI 自动完成日常工作。
